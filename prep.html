Fast-path for native install

The full guide is in pre-lab-installation; here's the speed-run for confident users:

macOS

# 1. R + RStudio Desktop (download from posit.co)
# 2. ImageMagick + uv via Homebrew
brew install imagemagick uv

# 3. R packages
Rscript -e 'install.packages(c("pavo","tidyverse","magick","jpeg","png"))'

# 4. Clone + verify
git clone https://github.com/AlfaroLab/eeb187-pavo-lab.git
cd eeb187-pavo-lab
Rscript scripts/verify_pipeline.R

Windows

# 1. R + RStudio Desktop (download from posit.co)
# 2. ImageMagick: download installer from imagemagick.org/script/download.php#windows
# 3. uv: see https://astral.sh/uv (one-line PowerShell installer)

# 4. R packages — same as macOS
Rscript -e 'install.packages(c("pavo","tidyverse","magick","jpeg","png"))'

# 5. Clone + verify
git clone https://github.com/AlfaroLab/eeb187-pavo-lab.git
cd eeb187-pavo-lab
Rscript scripts/verify_pipeline.R

Linux

sudo apt install imagemagick libmagick++-dev
curl -LsSf https://astral.sh/uv/install.sh | sh
# (R + RStudio Server from posit.co)
Rscript -e 'install.packages(c("pavo","tidyverse","magick","jpeg","png"))'
git clone https://github.com/AlfaroLab/eeb187-pavo-lab.git
cd eeb187-pavo-lab
Rscript scripts/verify_pipeline.R

If something breaks

Most problems and their fixes are documented in the README troubleshooting section. Common ones:

  • "udunits2 missing" on macOS: brew install udunits then re-run install.packages.
  • "libMagick++" missing on Linux: sudo apt install libmagick++-dev
  • R can't find uvx on PATH: in R, run Sys.getenv("PATH") and confirm ~/.local/bin is listed; if not, restart RStudio.
