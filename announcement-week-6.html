2. Where to put your fish images — MAKE THIS FOLDER TONIGHT

Use a consistent folder so every code example in walkthrough.R works copy-paste with one filename change. Make the folder now even before you have images in it — you'll thank yourself Wednesday.

Did you clone the repo? If yes, the folder already exists at eeb187-pavo-lab/images/student-fish/<your-lineage>/ with 5 starter species pre-loaded. Use any 3 of those and skip the rest of this section.

Otherwise, create the folder now. Replace <your-lineage> with your assigned family in lowercase (chaetodontidae, pomacanthidae, balistidae, or acanthuridae):

macOS / Linux

mkdir -p ~/Documents/eeb187-pavo-lab/images/student-fish/<your-lineage>

Then in R: setwd("~/Documents/eeb187-pavo-lab") at the top of every session.

Windows (PowerShell)

mkdir $env:USERPROFILE\Documents\eeb187-pavo-lab\images\student-fish\<your-lineage> -Force

Then in R: setwd("~/Documents/eeb187-pavo-lab") at the top of every session (R on Windows still understands ~ as your user folder).

Binder / Codespaces (cloud)

Folder already exists when you launch. Upload your JPGs via the RStudio Files pane (bottom-right) → click Upload button → drop into images/student-fish/<your-lineage>/. Binder note: uploads are erased after 90 minutes of inactivity — finish lab in one sitting or use Codespaces / Native.

Image naming

Use lowercase, hyphenated filenames so paths stay clean:

  • genus-species.jpg — e.g., chaetodon-auriga.jpg, pomacanthus-imperator.jpg
  • Multiple photos of the same species: genus-species-1.jpg, genus-species-2.jpg
  • Avoid spaces, capitals, parentheses, special characters — they break paths on some platforms

3. Pre-segment your images at home (single biggest time-saver)

Each fish image needs its background (water, reef, tank glass) removed before pavo's analysis works. Skip this step at home and you'll spend the first 30 minutes of lab on image processing instead of biology. Pick the easier of these two paths:

Path A — Local (best quality)

If your install of uv + imagemagick worked, run in R:

source("scripts/walkthrough.R")
segment_fish("images/student-fish/<your-lineage>/your-fish.jpg")
# Output: your-fish-segmented.jpg in the same folder

Path B — Web tool (no install needed)

Drag-drop your fish JPG to one of these (all free, no signup):

  • remove.bg — best known, fastest
  • photoroom.com — also free
  • clipdrop.co/remove-background — Stability-AI tool

You'll get a transparent PNG. Save it next to the original. Then in R:

source("scripts/walkthrough.R")
composite_to_white("images/student-fish/<your-lineage>/your-fish.png")
# Output: your-fish-segmented.jpg, ready for pavo

If neither works, the manual-crop fallback (Preview.app on macOS, Photos on Windows) is supported in the lab — your A values will be slightly less dramatic than the demo, but the directional A claim still holds.
